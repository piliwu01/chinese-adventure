# 國文冒險聯盟 使用與修改說明

本遊戲使用使用者提供的《115 學年度國中國文測驗解析卷（全）》，以選招、答題、攻擊與收服的方式複習國文。開啟交付包中的 Chinese_Adventure.html 即可遊玩，不需要安裝套件或建立帳號。

## 題庫與招式

原卷共 300 題，保留題幹、四個選項、答案、原始解析、原卷難易度與來源題號。可出戰 274 題，待複核 26 題；後者保留在 JSON 與複核清單中，不參與抽題。已核對 142 題基礎語文知識及 158 題課文文意理解。

| 原卷難度 | 統一教學招式 | 答對固定傷害 | 原卷題數 | 可出戰題數 |
| --- | --- | ---: | ---: | ---: |
| 難 | 破壞光線 | 150 | 6 | 6 |
| 中偏難 | 打雷 | 110 | 14 | 11 |
| 中 | 十萬伏特 | 90 | 164 | 148 |
| 中偏易 | 電擊波 | 60 | 48 | 43 |
| 易 | 電擊 | 40 | 68 | 66 |

所有夥伴使用上述統一教學招式選單，傷害依本遊戲規則固定結算。每種招式只抽對應難度的可用題目，不借用其他難度；同一難度全部抽完後重新洗牌。

## 開始遊戲

1. 用 Chrome 或 Edge 開啟 Chinese_Adventure.html，選擇出戰夥伴，按「開始冒險」。64 張角色立繪已內嵌，無網路仍可使用預設夥伴。
2. 選擇招式，閱讀題目，於 120 秒內選出答案。答對才造成表列傷害，答錯或逾時不造成傷害，對手會反擊。
3. 每題結束會顯示答案、原始解析與來源。回饋保留到下一題開始，請先閱讀再出招。
4. 對手生命值降至 0 即獲勝。仍存活時也可選「丟出精靈球」；對手 HP 低於或等於 35% 時抽易題，答對後收服機率為 92%；其他情況抽中等題，答對後收服機率為 35%。
5. 對手反擊造成 18–33 點傷害。落敗可恢復體力重新挑戰；下一場會重設退場動畫與上一題解析。

## 進度與題庫

學習紀錄、目前夥伴、圖鑑與連勝數保存在同一瀏覽器的 localStorage；更換瀏覽器、清除網站資料或隱私模式可能影響保存。重新開啟從冒險準備畫面開始，本場 HP、倒數與尚未結束的題目不保存。

首頁顯示已練習題數、累計答對次數、最後一次答錯的待加強題數。可以「下載進度備份」與「還原進度」。自訂搜尋到而不在預設 64 位名單的角色不納入重新開啟後的圖鑑恢復。

可匯入符合 schemaVersion 1 的 JSON 題庫。預設題庫已內建，毋須再次匯入。更新題庫請使用新的 bankId，以保留不同版本的紀錄；同名 bankId 會拒絕匯入。待複核題改為 active 前，須補足解析、確認選項及閱讀材料，並重新檢查。

本版是自學複習工具，HTML 與 JSON 均內含答案，不具考試防查看或跨裝置帳號功能。背景音樂為範本的原創 Web Audio 合成旋律，可由右上角控制配樂音量及音效；聲音需第一次操作後才能播放。額外角色搜尋需要網路。

## 檔案內容

- Chinese_Adventure.html：可直接開啟的完整遊戲。
- chinese-bank.json：完整 300 題，含 274 題 active 與 26 題 review。
- review-list.csv：待複核題目與原因。
- source/：可修改 React 原始碼、內建題庫、64 張立繪、CSS、音樂程式及建置腳本。
- verification.json：規則、抽題、保存與靜態渲染檢查結果及驗證限制。

## 修改與建置

在 source 資料夾使用 Node.js 與 npm，執行 npm install，再執行 npm run build。執行 node scripts/export-standalone.mjs 會把 dist 的程式、樣式與角色立繪匯出為獨立 HTML。正式使用前，應以目標瀏覽器重新開啟最終 HTML 並確認畫面、答題、音效及進度保存。

本次環境使用 scripts/build-portable.mjs 及官方 esbuild 套件的轉譯功能完成建置；一般環境可沿用 package.json 的 Vite 建置。scripts/verify-rules.mjs 可檢查難度池、傷害設定、抽題去重、無可用題目及進度讀寫邏輯。
